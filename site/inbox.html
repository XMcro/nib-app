Sending notes to your inbox

Nib for iPhone, iPad and Mac, with Nib Plus.

Nib’s inbox is an address that other apps and services can send notes to. Each note sent to it becomes a note in Nib the next time one of your devices syncs. It needs Nib Plus, with sync turned on.

Turn it on

In Nib, open Settings → Sync and choose “Turn on the inbox”. Nib shows the inbox’s address, which you can copy.

The address ends in a secret. Anyone who has the address can send notes to your inbox, so keep it as you would a password. If it gets out, “New address” replaces it at once, and the old one stops working.

What to send

Send a POST request to the address, with any of these:

  • title: the note’s first line;
  • text: the note’s text, read as Markdown: bold, italics, lists, checklists and links. A note has no headings, so a heading becomes a line of its own;
  • url: a web address, which goes on the note’s last line as a link.

They can be sent as JSON, as a form, or you can send the text alone. A post can be up to 100 KB. With curl, using the whole address Nib shows you:

curl https://sync.nibprivacy.com/v1/in/YOUR-ADDRESS \
  -H 'Content-Type: application/json' \
  -d '{"title": "Tide times",
       "text": "High water at **06:12**",
       "url": "https://example.com/tides"}'
curl https://sync.nibprivacy.com/v1/in/YOUR-ADDRESS -d 'Buy milk'

Where you can set a header, you can keep the secret out of the address: send to the address up to its last dot, and put what comes after the dot in an Authorization header. Then it isn’t written down anywhere addresses are, such as a log:

curl https://sync.nibprivacy.com/v1/in/THE-PART-BEFORE-THE-DOT \
  -H 'Authorization: Bearer THE-PART-AFTER-THE-DOT' \
  -d 'Buy milk'

What comes back

A note that was taken is answered with 200 and {"received":true}. Otherwise:

  • 400: there was nothing to keep. Send title, text or url, each as text;
  • 404: there is no inbox at that address. It may have been replaced, or the inbox turned off;
  • 402: Nib Plus isn’t active for the library;
  • 413: the post was over 100 KB;
  • 429: the inbox has taken 200 notes today, which is the most it takes in a day (counted in UTC);
  • 507: 200 notes are waiting, or 20 MB of them, which is the most it holds. Open Nib so it syncs and takes them in.

From Zapier

Add a “Webhooks by Zapier” step, which needs a paid Zapier plan. For Event choose POST, put your inbox’s address in URL, set Payload Type to JSON, and under Data add title, text and url as you need them, each with the value to send.

From IFTTT

Use the “Webhooks” service’s “Make a web request” action. Put your inbox’s address in URL and set Method to POST. The simplest way is to set Content Type to text/plain and put the note’s text alone in Body: it arrives as the note’s text whatever it contains. To send a title or a link as well, set Content Type to application/json and write the Body as JSON, as in the first example above.

From Shortcuts

Add a “Get Contents of URL” action with your inbox’s address. Tap Show More, set the method to POST, choose JSON for Request Body, and add title, text and url as you need them.

From your computer’s browser

Nib Web Clipper is an extension for Chrome, Edge and Firefox that saves web pages to your inbox. It encrypts each one in your browser before sending it, so, unlike a note sent in the other ways here, Nib’s server never has it in a form it can read.

Install Nib Web Clipper from your browser’s extension store. In Nib, open Settings → Sync and choose “Copy the code for Nib’s browser extension”. Then click the extension’s button in your browser’s toolbar, paste the code and choose “Use this code”. The code holds your inbox’s address, so keep it as you would the address. After “New address”, copy the code again and give it to the extension with “Use another clipper code”.

On a page you want to keep, click the extension’s button and choose what to keep: the link only, what you’ve selected, the article, the part on screen or the whole page. Then choose “Save to Nib”. You can change the title first, and add a note of your own. To keep some parts and not others, choose “Pick parts of the page”, click each part you want, and choose “Save to Nib” in the bar at the top of the page.

A clip keeps a page’s words: its headings, lists, tables and links, and not its pictures. A link or a selection becomes a note, and anything more becomes a page. A clip counts toward what the inbox holds and what it takes in a day, as any note sent to it does.

On iPhone and iPad there is nothing to install: share a page from Safari to Nib, and choose what to keep there.

When a note arrives

A note comes in the next time Nib syncs on any of your devices: when you open Nib, every so often while it’s open, or when you choose Sync now. On a device set to “Sync only when I ask”, it comes in when you choose Sync now. It goes into Notes, in the folder you’ve chosen for new notes if you’ve chosen one.

A note waits on the server for up to 30 days. One that no device has taken in by then is deleted.

Privacy

A note you send reaches Nib’s server readable, because the app or service that sends it can’t encrypt it for you. The server encrypts it the moment it arrives, so that only your devices can read it, and deletes it once one of them has taken it in. The Privacy Policy has the rest.
